# 代理流量观察台 · 0.2.2

Windows 上持续记录经过 Clash / Mihomo 代理节点的流量，按程序、目标和节点查看累计量。采集与网页独立运行，关闭网页不会停止记录。图表和页面资源全部本地加载，无远程分析服务。

[下载 Windows 便携版](https://github.com/yaozhihang2002/ProxyTrafficMonitor/releases/latest) · [提交问题](https://github.com/yaozhihang2002/ProxyTrafficMonitor/issues)

## 使用便携版

解压 ZIP 到可写目录，先打开 Clash，再启动 `ProxyTrafficMonitor.exe`。无需安装 Python 或 Codex。窗口可隐藏到托盘；“退出监测”停止记录。未设置开机自启。

如果自动识别失败，在网页“连接与存储设置”中填写本机控制接口与 Secret。接口不是代理端口，通常形如 `http://127.0.0.1:9090`，以客户端实际设置为准。不需要订阅链接，不依赖订阅商。Clash 必须启用兼容的本地控制接口；不是所有客户端打开后都能直接识别。

Secret 用 Windows DPAPI 加密，留空保留已有值。复制程序到另一台电脑后需重新设置。程序只读连接统计，不修改 Clash 配置或系统代理。

CSV 写入和保留维护独立运行；诊断页显示处理耗时、队列与延迟。在线使用 PASSIVE WAL 检查点，避免采集时执行全库 VACUUM；数据库容量设置仍为使用量与维护目标，文件物理大小可能高于当前有效数据量。

## 查看与交互

- 顶部明确区分“全部累计”和“时间段观察”。“从现在开始”只改变查看范围，不删除历史数据。
- 趋势图为每分钟字节增量，支持近 15 / 30 / 60 分钟。上传橙色虚线及方形点，下载蓝色实线及圆形点；图例可隐藏一条序列。
- 鼠标在绘图区移动显示读数，点击固定；也可用左右方向键、Home / End、Enter 和 Escape。“放大小流量”使用明确标注的对数刻度，读数仍是真实字节数。
- 最近活动独立于累计范围、搜索和日期。程序排行约统计最近 5 分钟，按 10 秒合并，窗口边缘可能有约 10 秒偏差。全局分钟趋势保留 7 天，界面当前显示最多 60 分钟；程序近期明细保留 60 分钟且受数量限制。
- 明细限高滚动，可直接输入展示条数；日期、全部项、导出和连接设置直接显示在工具栏。暂停网页或查看详情时，后台仍继续记录。
- 大流量提醒默认关闭。开启后才累计，不补发旧提醒；持续超限不重复提醒，回落至阈值 80% 后再次越限才重新提醒，每个程序至少间隔 10 分钟。系统展示通知取决于 Windows 设置。

## 数据与保留

数据在程序目录 `data/` 下。持续 CSV 每 10 秒合并追加代理流量增量，不必保持网页打开。CSV 被占用时先保存到 SQLite 待写队列，解锁后自动补写；待写队列达上限会暂停采样并显示错误，避免无限占用磁盘。

CSV 按日期与约 32 MiB 分卷，默认保留 30 天、总预算 1024 MiB，超限清理旧分卷。数据库默认保留 7 天连接、90 天目标明细，并有数量和容量目标限制。生命周期累计独立保存，不随明细清理而清零。临时文件、当前分卷和被占用文件可能让目录暂时超预算。

网页汇总导出最多 5000 行，与持续 CSV 日志不同。修改 CSV 前请先复制，勿编辑或替换程序正在写入的文件。备份使用 SQLite backup API，或退出程序后复制完整 data 目录。

## 统计边界

只计入经过代理节点且未匹配 DIRECT / REJECT 的连接。此值不是订阅账单，也不能可靠区分共享节点来自哪个订阅文件。首次启动时已有连接建立基线，旧字节不追溯；正常约每秒采样，短连接、休眠和停机可能漏记。缺失采样不伪造零值，中断后恢复的增量归入恢复分钟。

通过源地址、源端口与 Windows socket 表匹配程序和父进程；共享 UDP 端口、权限不足或进程退出时明确标记待核实。无法将共享进程的流量精确拆到每个聊天。IP 可能是 DNS 映射地址或为空，不能视为真实服务器 IP。

不解密 HTTPS，不保存请求正文、令牌或订阅链接。仅监听 127.0.0.1；能访问此端口的本机进程也能读取统计。

## 异常恢复与诊断

正常打开 EXE 会启动一个轻量守护进程，后台异常退出后自动恢复；连续失败按 2、4、8 秒逐步退避，最长 60 秒。明确点击退出不会自动重启。恢复后保持托盘状态。Windows 子进程清理作业会清理崩溃实例的采集后代；若系统不允许关联，会在日志中标明。

本地 data/lifecycle.log 和 data/supervisor.log 分别记录后台与守护进程的生命周期。每份最多 1 MiB 并保留 3 份轮转，总计约 8 MiB，不记录订阅凭据或请求正文。

守护进程不能在整台机器关机、注销或自身被终止后继续运行；请正常双击 EXE 启动。程序不自动创建开机任务或 Windows 服务。中断期间的流量不能补记。此恢复机制不代表所有死锁或系统异常已解决。
